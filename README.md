# 🧠 Constructeur de Prompt ACTIF

Cet outil interactif permet de construire facilement des prompts efficaces pour les intelligences artificielles en suivant le modèle ACTIF :

- **A — Action** : Ce que l’IA doit faire
- **C — Contexte** : Le cadre de la demande
- **T — Tonalité** : Le style attendu
- **I — Identité** : Le rôle que l’IA doit jouer
- **F — Format** : La forme de la réponse

## 🚀 Utilisation

1. Ouvrez le fichier `index.html` dans un navigateur.
2. Remplissez les champs guidés (ACTIF).
3. Le prompt est généré automatiquement.
4. Cliquez sur "Copier le prompt" pour le récupérer.

## 🌐 Mise en ligne

Vous pouvez héberger ce fichier gratuitement sur GitHub Pages pour y accéder depuis n’importe où.

## 🔗 Exemples

- Ex : Agis comme un expert RH. Pour une entreprise qui souhaite améliorer son onboarding. Propose une méthode. En utilisant un ton professionnel. Sous forme de liste à puces.
